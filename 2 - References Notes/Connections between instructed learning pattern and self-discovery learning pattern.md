# Connections between two types of learning pattern
Typically, we learn by two seemingly different ways. We learn something through listening to the instructors, or reading some utility books, which is called *instructed learning pattern*. If we have no such instructor, we have to learn by reading ourselves and understanding the outer world, which is *self-discovery learning pattern*.

The *instructed learning pattern* doesn't mean that we don't need to spend spiritual efforts. Instead, like *self-discovery learning pattern*, we still have to take efforts to understand the book and the instructors' words.

These two learning pattern should be treated as the same, they both need positive understanding, reflection, imagination and etc.
